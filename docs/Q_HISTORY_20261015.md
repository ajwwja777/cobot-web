# 单轮 Q 历史选择（2026-10-15）

EXPO / RLT Online 的每轮已采样 Q 保存到各自 run 的 telemetry/rollout-history.sqlite3，按真实 episode UUID 隔离。默认跟随当前/最近回合，选择历史后保持选择；刷新网页、模型卸载后仍能读取落盘记录。回合标签显示时间、UUID 和 Actor 版本。

原 rollout.json 只有最近一轮，已经覆盖的旧 Q 无法还原，不补造曲线。现有进程由独立后台采集保存，新进程在原 telemetry 工作线程直接归档；不新增 GPU 推理或控制环磁盘操作。滚动快照合并去重，保留已归档的早期点，按 run/参数隔离。

验证：9 项 RL Python、9 项 Web Python、6 项前端 DOM 通过，包括跨回合选择、重启读取、并发写入、滚动窗口合并、无浏览器后台归档。现场激活另记，未操作机器人或训练状态。
